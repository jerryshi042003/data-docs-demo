# Product logo sources

Logos identify systems in synthetic educational examples; they do not imply endorsement.

- Excel and SharePoint: Microsoft Office Fabric brand SVG CDN (20221201.001), `excel_48x1.svg` and `sharepoint_48x1.svg`.
- Azure Function Apps, Logic Apps and Storage: official Azure Public Service Icons V24 archive, https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip.
- Dynamics Sales: official Dynamics 365 scalable icon archive, https://download.microsoft.com/download/498606aa-6d27-4f13-aa5c-1401078c153b/Dynamics-365-icons-scalable.zip.
- Salesforce, Databricks and Power BI: https://github.com/gilbarbara/logos/tree/main/logos (`salesforce.svg`, `databricks-icon.svg`, `microsoft-power-bi.svg`).
- Microsoft, Chrome and Azure DevOps: retained vendor-logo assets from the accepted architecture reference.

SVGs are embedded into the generated system diagrams by the build; no live third-party image request is needed.
